# Study.ai: guest access + 50 additions

Guest access works without an account. Guest coursework and preferences stay in the current browser, with an export/restore flow for portability. Google connections remain available only to signed-in accounts.

1. **Task inbox** — Capture personal study tasks in one list. Find it in **Toolkit**.

2. **Task subtasks** — Break a task into checkable steps. Find it in **Toolkit**.

3. **Priority sorting** — Choose high, medium, or low priority and sort your task inbox. Find it in **Toolkit**.

4. **Recurring tasks** — Repeat a completed task daily or weekly. Find it in **Toolkit**.

5. **Study time blocks** — Schedule a dated study session with a start time and duration. Find it in **Toolkit**.

6. **Weekly agenda** — See coursework and study blocks across the next seven days. Find it in **Toolkit**.

7. **Calendar export** — Download deadlines and time blocks as an ICS calendar file. Find it in **Toolkit**.

8. **Workload budget** — Compare estimated task minutes with your available time. Find it in **Toolkit**.

9. **Deadline countdowns** — See days left or overdue for every dated assignment. Find it in **Toolkit**.

10. **Daily top three** — Pin up to three study tasks as today’s priorities. Find it in **Toolkit**.

11. **Pomodoro timer** — Run configurable focus and short-break intervals. Find it in **Focus**.

12. **Long-break cycle** — Take a longer break after every fourth completed focus interval. Find it in **Focus**.

13. **Study stopwatch** — Track open-ended study time and save completed sessions. Find it in **Focus**.

14. **Focus session history** — Keep a dated record of focused minutes. Find it in **Focus**.

15. **Weekly focus goal** — Set a weekly minutes target and see your progress. Find it in **Focus**.

16. **Focus streak** — Count consecutive days with logged study sessions. Find it in **Focus**.

17. **Distraction parking lot** — Write down distractions to revisit after studying. Find it in **Focus**.

18. **Reflection journal** — Save dated reflections on what helped and what to change. Find it in **Focus**.

19. **Ambient study sound** — Generate optional background noise locally in your browser. Find it in **Focus**.

20. **Breathing pacer** — Follow a visual paced-breathing exercise. Find it in **Focus**.

21. **Cornell notes** — Write cues, class notes, and a summary in a structured note. Find it in **Active recall**.

22. **Feynman explanation check** — Review an explanation’s length, sentence complexity, and definition coverage. Find it in **Active recall**.

23. **Blurting comparison** — Compare a from-memory explanation with a reference by keyword coverage. Find it in **Active recall**.

24. **Concept glossary** — Keep searchable terms and definitions by course. Find it in **Active recall**.

25. **Concept map** — Visualize saved terms and the relationships you explicitly add. Find it in **Active recall**.

26. **Mnemonic builder** — Build an acronym and an editable memory sentence from a term list. Find it in **Active recall**.

27. **Exam revision schedule** — Spread chosen topics across the days before an exam. Find it in **Active recall**.

28. **Written practice exam** — Answer a selected set in writing, reveal a key, and self-assess. Find it in **Active recall**.

29. **Mistakes notebook** — Automatically collect missed quiz answers and mark reviewed mistakes. Find it in **Active recall**.

30. **Topic confidence tracker** — Rate your confidence and prioritize low-confidence topics. Find it in **Active recall**.

31. **Reverse flashcards** — Recall the term from its definition. Find it in **Card lab**.

32. **Typing flashcards** — Type an answer and compare it with the saved answer. Find it in **Card lab**.

33. **True or false game** — Judge whether a prompt and answer pair match. Find it in **Card lab**.

35. **Starred cards** — Bookmark individual flashcards. Find it in **Card lab**.

37. **Progressive hints** — Reveal an answer a few words at a time. Find it in **Card lab**.

38. **Merge study sets** — Combine selected sets into a new set without changing the originals. Find it in **Card lab**.

39. **Duplicate study sets** — Create an editable copy of a set. Find it in **Card lab**.

40. **Study-set search** — Search titles, prompts, and answers. Find it in **Card lab**.

41. **Grade what-if** — Estimate a course average after a hypothetical future score. Find it in **Grade lab**.

42. **Target-grade calculator** — Calculate the score needed on a future weighted item. Find it in **Grade lab**.

43. **Grade type breakdown** — Compare results across homework, quizzes, tests, and projects. Find it in **Grade lab**.

44. **Grade trajectory chart** — Plot recorded grade percentages in date order. Find it in **Grade lab**.

45. **Revision checklists** — Create and complete course-specific revision steps. Find it in **Progress**.

46. **Reading queue** — Save readings, safe links, notes, and page progress. Find it in **Progress**.

47. **Learning milestones** — Earn transparent badges from actual study activity. Find it in **Progress**.

48. **Workspace restore** — Import a JSON backup as new records with safe ID remapping. Find it in **Progress**.

49. **Printable study sheets** — Open a clean study guide that can be printed or saved as PDF. Find it in **Card lab**.

50. **Accessibility preferences** — Save dark mode, larger text, and reduced-motion preferences. Find it in **Progress**.

All features use local calculations or user-entered data. Explanation checks and recall comparisons do not evaluate factual correctness. Grade scenarios are estimates using recorded item weights. Workspace restores create new coursework and tool records; review schedules and game history restart for restored sets.
